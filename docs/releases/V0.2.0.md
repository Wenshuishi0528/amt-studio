# AMT Studio 0.2.0 Private Beta

AMT Studio 0.2.0 是首个公开 Private Beta。它把歌曲导入、Hyak/Slurm 任务、
多轨结果取回、原曲与 MIDI 试听、钢琴卷帘编辑和 MIDI 导出整合到一个原生 macOS
应用中。

AMT Studio 0.2.0 is the first public Private Beta. It combines song import,
Hyak/Slurm job handling, multitrack result retrieval, source/MIDI audition,
piano-roll editing, and MIDI export in one native macOS application.

## 中文

### 主要功能

- MuScriptor 完整多轨识别，以及可选的 GAME large 主唱旋律单轨。
- 多歌曲队列、多个活动 Hyak 项目监控、任务用时和预计完成时间。
- 自动选择兼容 GPU，并可只读查看节点快照、自己的队列和 Slurm 预计启动时间。
- 全部音轨总览、逐轨试听、静音、独奏、音量和单轨钢琴卷帘编辑。
- 新增、删除、移动和调整音符长度；人工修改可保存、撤销并生成可追溯版本。
- 主旋律空缺检测与所选片段重新计算；原始识别结果不会被静默覆盖。
- 延音碎片检测和可撤销修复。
- 同曲与跨歌曲的音轨复制、合并和删除。
- 当前音轨、当前合奏和完整识别版本 MIDI 导出。
- 长歌曲自动延长 Slurm 时限，以及满足检查点条件的超时续算。

### 运行边界

- 发布附件面向开发者和测试者，暂时不是经过 Apple 公证的独立安装包。
- macOS 应用需要与本仓库和轻量 Python 后台配套使用。
- 默认大模型路径需要使用者自己的 Hyak/SSH/Duo/Slurm 权限及合法模型资源。
- 本发布不包含私人歌曲、转录结果、数据集、模型权重、账号凭据、私人路径或集群
  日志。
- 模型输出可能漏音、误分类、生成多余音符或切碎延音；人工修改不会自动训练模型。

## English

### Highlights

- MuScriptor full multitrack transcription and an optional GAME large
  lead-vocal melody track.
- Multi-song queueing, multiple active Hyak project monitors, stable elapsed
  time, and coarse completion estimates.
- Automatic compatible-GPU selection plus a read-only view of node snapshots,
  owner-scoped queue counts, and Slurm estimated start times.
- All-track overview, per-track audition, mute, solo, volume, and detailed
  piano-roll editing.
- Note creation, deletion, movement, and resizing with saved, undoable,
  traceable user edits.
- Melody-gap detection and selected-region recomputation without silently
  replacing raw model output.
- Fragmented-sustain detection and undoable repair.
- Track copy, merge, and removal within a song and across songs.
- MIDI export for the selected track, current arrangement, or complete
  recognition version.
- Duration-aware Slurm wall time and safe timeout continuation when a verified
  checkpoint exists.

### Release boundaries

- The attached build is for developers and testers; it is not a notarized
  standalone installer.
- The macOS application works with this repository and its lightweight Python
  backend.
- The default large-model route requires the operator's own
  Hyak/SSH/Duo/Slurm access and legally obtained model assets.
- This release excludes private songs, transcriptions, datasets, model
  weights, credentials, private paths, and cluster logs.
- Model output may omit notes, misclassify instruments, emit extra notes, or
  fragment sustained tones. Manual edits do not automatically retrain models.
