# AMT Studio 0.2.1 Private Beta

AMT Studio 0.2.1 是一个维护版本，发布 v0.2.0 之后已经完成的任务恢复修复和音乐库
显示改进。它不包含单独进行中的 Task 007D 数据准入研究。

AMT Studio 0.2.1 is a maintenance release for completed job-recovery and
library-presentation work since v0.2.0. It does not include the separate
in-progress Task 007D data-admission research.

## 中文

- 已完成的 Hyak 作业离开活动 `squeue` 后，软件会对精确的无效 Job ID 响应继续
  查询 `sacct`，从而恢复状态和结果；其他 SSH、网络和调度错误不会被隐藏。
- “最近完成”歌曲组可以折叠或展开，并记住选择；搜索时仍会显示匹配的已完成歌曲。
- 版本统一更新为 `0.2.1 (3)`。

## English

- When a completed Hyak job leaves the active `squeue` view, the exact invalid
  job-ID response now falls through to `sacct` so status and results can be
  recovered. Other SSH, network, and scheduler errors remain visible.
- The completed-song group can be collapsed persistently while search still
  reveals matching completed songs.
- Product and package metadata advance together to `0.2.1 (3)`.

## Release boundaries / 发布边界

- The macOS archive is an ad-hoc-signed, unnotarized developer/tester Private
  Beta and still works with this repository and its lightweight Python backend.
- The release excludes private songs and transcriptions, datasets, model
  weights, credentials, personal Hyak identity/storage data, and cluster logs.
- Model output can still contain missing, extra, fragmented, or misclassified
  notes. This maintenance release does not claim improved transcription
  accuracy.

## Verification / 验证

- `make check`: 290 Python tests and 60 Swift tests passed; three private live
  integration tests were skipped as expected.
- The clean Xcode Release build and standalone Apple Silicon package both
  succeeded.
- The packaged app is arm64, reports `0.2.1 (3)`, passes strict code-signature
  verification, and completed a launch smoke test.
